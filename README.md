## 🤖 AI-Powered Analytics with Claude AI + MCP

This project integrates **Claude AI with Power BI through the Model Context Protocol (MCP)** to enable AI-assisted interaction with the Power BI semantic model and business KPI analysis.

### 🔗 Architecture

**Power BI Semantic Model → MCP → Claude AI → Business Insights**

### ⚙️ How It Works

1. **Power BI Semantic Model**

   * Built a semantic model containing customer, session, product, and review data.
   * Created DAX measures for key business KPIs such as conversion rate, click rate, and like rate.

2. **MCP Integration**

   * Connected the Power BI environment with **Claude AI using the Model Context Protocol (MCP)**.
   * MCP provides the standardized connection that allows Claude to work with the available Power BI data/context.

3. **Claude AI Analysis**

   * Used Claude AI to assist with KPI analysis and business-question exploration.
   * Asked natural-language questions to analyze business metrics and identify trends from the Power BI data.

4. **Business Insights**

   * Used the AI-assisted workflow to interpret KPI trends and support dashboard analysis.
   * Identified that conversion rate reached **10.2% in December**, compared with a **5% low in October**, while click rate (**15%**) and like rate (**37%**) remained relatively flat.

### 🚀 Impact

The Claude AI + MCP workflow helped reduce the dashboard development and analysis effort from approximately **10 hours to 1 hour**, representing an estimated **90% reduction in development effort** for this project workflow.

### 🛠️ Technologies

* **Power BI** – Semantic modeling, visualization & DAX
* **Claude AI** – AI-assisted analysis and insight generation
* **MCP** – Model Context Protocol for AI-to-data interaction
* **SQL Server** – Data cleaning and transformation
* **Python** – Data processing
* **NLTK VADER** – Sentiment analysis
